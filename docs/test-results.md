## 已发现的体验问题

- AI 回复可能按语音句号拆成多个气泡，例如“适合。”与后续解释分开显示；不影响内容正确性，后续可优化为按同一轮对话合并。
- 主 JavaScript gzip 后约 2.74 MB，后续可通过路由或组件懒加载降低首屏资源体积。

## 已解决的关键问题

- RTC Token 权限字段序列化顺序导致签名不一致。
- 公网回调隧道失效导致模型无回复。
- 深度思考导致实时语音延迟过长。
- `botName` 与 RTC 智能体用户 ID 不一致导致 AI 字幕被前端过滤。
