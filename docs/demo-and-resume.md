# 懂小智项目演示与简历材料

## 一句话项目介绍

懂小智是一个基于火山引擎 RTC、FastAPI、方舟大模型和知识库 RAG 的实时语音课程顾问，能够完成语音识别、资料检索、流式回答、语音合成和同步字幕，并对价格、就业承诺等高风险问题进行回答边界控制。

## 面试高频问题回答提纲

### 为什么使用 RAG，而不是微调？

课程资料会变化，RAG 可以直接更新外部资料并追踪回答依据；微调更适合改变模型行为或能力，更新成本更高。这个项目首先需要解决知识更新和减少编造，因此选择 RAG。

### 为什么实时语音关闭深度思考？

实时对话首先要求快速反馈。课程咨询问题以直接、可核验的回答为主，深度思考增加的等待时间大于收益，因此关闭；复杂的离线分析可以单独使用推理模型。

### 为什么拆成 3001 和 3002 两个 FastAPI 服务？

`3001` 包含 Token、Swagger 和调试能力，只在本地使用；`3002` 只保留健康检查和带鉴权的模型回调。这样即使通过公网隧道接入 RTC，也不会把本地管理接口和 Token 签发能力一并暴露。

### 如何降低模型编造？

先检索指定知识库，将召回片段作为系统上下文；提示词要求只依据资料回答，对动态信息、就业承诺和知识库外问题设置明确降级策略，并使用实际测试用例验证。

### 最有价值的一次排障是什么？

AI 已能播放语音但页面没有 AI 字幕。通过浏览器日志确认 RTC 已发送大量字幕消息，说明云端链路正常；继续检查前端过滤逻辑，发现页面配置的 `botName` 与真实 RTC 智能体 ID 不一致。统一身份后字幕恢复，并添加回归测试防止复发。
